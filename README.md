# Pomodoro Timer

Single-page, entirely local Pomodoro timer for work (and maybe life) with reflection journaling and CSV export.

## Documentation
- [API, Functions, and Usage Guide](docs/api.md)

## Quick Start
- Open `webapp/index.html` in a browser.
- Press `Cmd/Ctrl + Enter` to start a 25-minute Pomodoro and follow the on-screen prompts.
